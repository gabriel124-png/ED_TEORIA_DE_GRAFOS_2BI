Grafos em busca do resgate.

Trabalho educacional do segundo bimestre de Grafos. O objetivo é desenvolver um grafo que simule algoritmos de busca pelo caminho mínimo, como os utilizados em mapas digitais. O mapa foi fornecido pelo professor em sala de aula, por meio de uma imagem, e devemos desenvolver um algoritmo baseado nela.

Funcionalidades

O projeto implementa um simulador de navegação espacial desenvolvido em C, utilizando conceitos de teoria dos grafos e estruturas de dados para representar sistemas estelares conectados por rotas. O programa combina exploração de um mapa interativo, gerenciamento de conexões e um minijogo de combate espacial, permitindo que o usuário explore o universo e realize viagens entre diferentes sistemas.

Visualização e exploração do mapa: o mapa espacial é construído em memória por meio de uma matriz de caracteres, que posteriormente é apresentada em uma janela de visualização. Os sistemas são posicionados de acordo com coordenadas predefinidas, convertidas para linhas e colunas, enquanto sistemas sem posições previamente estabelecidas são direcionados para uma região inferior do mapa. Os sistemas criados durante a execução recebem posições fixas. A representação visual inclui regiões identificadas por nomes, sistemas estelares, rotas e a posição atual da nave. Os sistemas são identificados por seus nomes e números, enquanto diferentes símbolos permitem distinguir a nave, os vizinhos acessíveis e os demais pontos do mapa.

Representação gráfica das rotas: as conexões entre os sistemas são desenhadas com diferentes caracteres, de acordo com suas características. Rotas grandes são representadas por linhas contínuas, rotas médias por linhas tracejadas e rotas pequenas por linhas pontilhadas. As rotas bloqueadas são identificadas pelo caractere x, permanecendo visíveis no mapa. Cruzamentos são representados pelo símbolo +, e o desenho das conexões inclui mecanismos para tentar desviar de outras rotas quando há sobreposição. O sistema também posiciona os nomes dos locais próximos aos respectivos pontos, avaliando diferentes posições para reduzir a sobreposição entre textos. A janela de visualização pode ser movimentada com as teclas W, A, S e D, sem a necessidade de pressionar Enter. A interface apresenta informações sobre a localização atual da nave, a região visível do mapa, a legenda dos símbolos e os vizinhos com rotas livres.

Consulta de sistemas e conexões: o programa permite consultar os sistemas vizinhos de determinado local, utilizando seu nome ou número identificador. A consulta apresenta as conexões existentes, seus pesos e seus estados, permitindo identificar quais rotas estão disponíveis ou bloqueadas. Também é possível verificar a existência de uma conexão direta entre dois sistemas, consultar suas características e medir o tempo gasto nessa busca. Essas operações facilitam a exploração do grafo e a identificação das conexões existentes no universo simulado.
Gerenciamento de sistemas e rotas: o sistema permite adicionar novas conexões e bloquear rotas existentes, atualizando a representação do mapa conforme as alterações realizadas. Também pode criar novos sistemas durante a execução, atribuindo-lhes posições no mapa e estabelecendo conexões com outros locais. A criação de novas rotas considera condições como a validade do peso, a distinção entre os sistemas de origem e destino e a existência de conexões anteriores. O mapa procura posicionar os novos elementos de maneira que não prejudiquem a visualização das estruturas existentes. Entretanto, as alterações realizadas durante a execução são mantidas apenas em memória e não são gravadas no arquivo mapa.csv, sendo perdidas quando o programa é encerrado.

Simulação de viagens espaciais: a nave pode viajar entre sistemas diretamente conectados por rotas livres. Antes de iniciar uma viagem, o programa verifica se o destino existe, se é diferente da localização atual, se há uma conexão entre os sistemas e se a rota está disponível. Quando as condições são atendidas, é iniciado um minijogo de combate espacial que determina o resultado da viagem. Após a conclusão da fase, o mapa é atualizado para refletir o resultado obtido.
Minijogo de combate espacial: durante uma viagem, o jogador controla uma nave representada pelo caractere ^, posicionada na parte inferior de uma grade de sete colunas por oito linhas. Os inimigos, representados por V, descem progressivamente pelo cenário. O jogador pode movimentar a nave para a esquerda ou para a direita e disparar tiros para eliminar os adversários. Cada disparo elimina apenas o inimigo mais baixo presente na coluna ocupada pela nave. Quando um inimigo alcança a última linha, o jogador perde uma vida. A fase começa com três vidas, e o objetivo é eliminar uma quantidade de inimigos determinada pelo perigo da rota: são necessários oito inimigos para o nível de perigo 1 e vinte para o nível 5. A frequência de surgimento dos inimigos também aumenta conforme o perigo. O jogador pode abandonar a fase utilizando a tecla q.

Consequências das viagens: o resultado do minijogo determina o que acontece com a nave e com a conexão utilizada. Quando o jogador vence, a nave é deslocada para o sistema de destino, e a rota permanece livre. Se todas as três vidas forem perdidas, a conexão é bloqueada nos dois sentidos. Caso o jogador abandone a fase, a posição da nave e o estado da rota permanecem inalterados. Dessa forma, as viagens podem modificar a disponibilidade das conexões e influenciar as possibilidades de exploração do mapa.
Leitura e validação dos dados: o programa carrega a estrutura inicial do universo a partir de um arquivo CSV, utilizando uma função específica para interpretar os sistemas, suas conexões e os respectivos pesos. O carregamento permite diferentes separadores, identifica conexões duplicadas e pode criar sistemas encontrados apenas como vizinhos de outros locais. Pesos inválidos são sinalizados com informações sobre a linha correspondente, permitindo que a leitura continue quando possível. O tempo de carregamento também é medido, possibilitando acompanhar o desempenho dessa operação.

Medição de desempenho: determinadas operações, como o carregamento do mapa e a busca por conexões diretas, possuem medição de tempo de execução. Esse recurso permite observar o custo temporal dessas operações e oferece uma base para futuras análises de desempenho dos algoritmos utilizados na manipulação do grafo.

Limitação atual — busca pelo caminho mínimo: embora o projeto utilize um grafo ponderado e permita consultar conexões diretas entre sistemas, a implementação descrita ainda não calcula o caminho mínimo entre dois destinos. A função caminhominimo encontra-se apenas comentada em mapa.h. Portanto, a busca pelo menor percurso entre sistemas permanece como uma funcionalidade a ser implementada, caso faça parte dos requisitos do trabalho acadêmico.

Tecnologias utilizadas — O projeto foi desenvolvido inteiramente em C, utilizando apenas bibliotecas padrão da linguagem e do sistema. Os dados do mapa são armazenados em um arquivo .csv, que contém as informações dos sistemas e suas conexões.

Como executar no Linux — Primeiramente, é necessário instalar o Git e o GCC, caso ainda não estejam instalados. Para isso, abra o terminal e execute o comando sudo apt install git gcc. Se o Git já estiver instalado, basta executar sudo apt install gcc. Para confirmar se as ferramentas estão disponíveis, utilize os comandos git --version e gcc --version.
Em seguida, abra o terminal e acesse a pasta na qual deseja armazenar o projeto utilizando o comando cd, seguido do caminho desejado. Por exemplo, para acessar a pasta Documents, utilize cd ~/Documents.
Dentro da pasta escolhida, execute o comando git clone https://github.com/gabriel124-png/ED_TEORIA_DE_GRAFOS_2BI.git para baixar o projeto do GitHub. Caso o projeto já tenha sido baixado anteriormente e você queira obter as atualizações, entre na pasta do repositório e execute git pull.
Após o download, acesse a pasta do projeto com o comando cd ED_TEORIA_DE_GRAFOS_2BI. Para visualizar os arquivos disponíveis, utilize o comando ls e identifique os arquivos .c necessários para a compilação.
Para compilar o projeto, utilize o comando gcc, informando os nomes e os caminhos dos arquivos .c necessários, seguido de -o e do nome desejado para o executável. Por exemplo, se os arquivos estiverem organizados dessa maneira, utilize gcc mapa.c main.c lercsv.c nave/nave.c -o jogo. Nesse caso, o executável gerado será chamado jogo.
Por fim, para executar o programa, utilize o comando ./jogo no terminal. Se a compilação for concluída sem erros e os arquivos necessários estiverem nos locais esperados, o programa será iniciado.
